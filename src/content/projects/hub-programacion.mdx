# Hub de Programación

## Problema

Los estudiantes necesitaban acceder a laboratorios
de programación y hardware desde ubicaciones remotas.

## Solución

Se desarrolló una plataforma educativa con backend
Node.js, comunicación con dispositivos Arduino y
gestión remota de laboratorios.

## Tecnologías

- Node.js
- Express
- React
- TypeScript
- MariaDB
- Arduino
- Docker
- PM2

## Mi participación

Participé en el desarrollo backend, integración de
servicios, base de datos, autenticación y laboratorio
remoto.

## Arquitectura

La solución separa interfaz, lógica de aplicación,
servicios de comunicación y dispositivos físicos.

## Resultado

Una plataforma capaz de integrar programación,
hardware y acceso remoto dentro de un único entorno.
